# MediaPipe removed the legacy `mp.solutions` API in the 0.10.2x series.
# VigilEye supports BOTH APIs and auto-detects which one you have:
#
#   Option A (recommended, zero extra setup) - legacy 'solutions' API:
#       pip install "mediapipe>=0.10.9,<0.10.22"
#
#   Option B (current release) - modern 'tasks' API. Works identically,
#   but needs a one-time model download:
#       pip install mediapipe
#       python -m vigileye.landmarks --download
#
# Check which backend you have:  python -m vigileye.landmarks
